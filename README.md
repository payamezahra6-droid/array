# DSA Assignment 1 – Array

## 📌 Description
This project is part of my Data Structures and Algorithms (DSA) Assignment 1. It focuses on understanding and implementing array concepts in Java.

## 🎯 Objectives
- Understand the basic concept of arrays.
- Learn how array elements are stored and accessed.
- Practice array implementation in Java.
- Improve problem-solving and programming skills.

## 🛠️ Technologies Used
- **Language:** Java
- **IDE:** IntelliJ IDEA

## 📚 Concepts Learned
- Array declaration and initialization
- Accessing and managing array elements
- Basic array operations
- Understanding data structures

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run the `Main.java` file.
